# 数据与兼容边界

物理表包括 meta、collections、versions、commits、receipts、index_defs、index_values、pins、consumers。versions 的主键为集合、键、修订；body 的 SQL NULL 表示删除，JSON null 只能作为文档字段。collections 保存当前模式；index_values 是当前 head 的投影。index_defs 的 kind 区分 equality 与 range 索引（旧文件打开时自动补列并视为 equality），index_order 支撑范围索引的令牌区间扫描。commits 保存完整的操作序列；receipts 保存不受历史回收影响的请求摘要与结果。幂等键不能被不同操作复用，回放不重新执行前置条件。

floor 是仍可读取的最早修订，不代表每条物理版本的最小修订；每个键在 floor 之前的最后版本可能是构造 floor 读视图的基准，必须保留。commits 仅需保存大于 floor 的提交，消费者从自己的 ack 之后读取。pin 与消费者位置不能低于现存 floor。

模式包含 fields、required、additional，支持点路径类型；additional=false 限制顶层未知根字段，不递归禁止已声明对象中的子字段。字段不允许 null，除非该字段未声明类型；缺失可通过 required 控制。integer 排除 bool，number 接受整数及有限浮点。JSON 对象不允许非字符串键；浮点必须有限。索引忽略缺失字段与对象/数组，空值作为可索引标量，数值 1 和 1.0 共用索引值，true 与 1 不共用。

等值索引使用标量精确令牌；范围索引使用保序令牌：数值经符号翻转的双精度 64 位有序编码（超出有限双精度域的整数饱和到端标记），字符串按 UTF-8 字节十六进制保序，空值、布尔、数值、字符串以不同令牌前缀分组，跨类型比较在谓词复核阶段落空。范围谓词的上下界都按闭边界产生候选，严格不等号由 `matches` 复核，保证同令牌不同表示（如 1 与 1.0）在边界处不漏项。查询计划在 `access=range_index` 时返回 `index` 与 `bounds`；回退版本扫描时给出 `reason`（force_scan、历史读版本、无合取比较、无匹配范围索引、不可索引边界值）。范围索引不登记唯一约束，唯一性仍只由 equality 索引在写入路径即时保证。

游标携带数据库身份、谓词摘要、读版本和最后键，并由数据库私有密钥签名。它不是权限凭据，不冻结模式，也不是保留租约。需要稳定的长时间读取，调用者自行管理具名保留点。

副本包是内部可信通道数据，校验和只用于检测传输损坏。正常备份恢复新主库保留逻辑内容而更换身份；副本初始化保留上游身份。分段追赶未完成时暂不提供当前索引，避免最新唯一约束错误约束中间历史视图。目录 epoch 可在没有文档提交时前进，最终空提交包仍能传递新的模式与索引。
